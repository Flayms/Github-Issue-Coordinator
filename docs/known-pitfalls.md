| Inline styles under the dashboard's CSP                                          | Since #60 the CSP is `style-src 'self'`, so a `style="…"` attribute or a `<style>` block in the dashboard's HTML is silently ignored by the browser (the old inline CSS would no longer apply)                                                                                                                                                                                                                                                           | Styles are Tailwind classes in the components or rules in `src/dashboard/styles.css`, never a React `style` prop; sizes from data use classes spelled out in full (e.g. the bar's `w-1/10`…`w-full`), since Tailwind only finds classes written literally.
